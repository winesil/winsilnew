# 🍷 קופה — ניהול הכנסות וחייבים (Streamlit + Google Sheets)

אפליקציית קופה שרצה כאתר עצמאי (לא תלוי ב-Claude בכלל), ושומרת את כל הנתונים
ישירות בקובץ **wine_inventory** שלך ב-Google Drive. עובדת מכל מכשיר — נייד, טאבלט, מחשב —
דרך קישור אחד.

---

## שלב 1 — יצירת "חשבון שירות" (Service Account) בגוגל

זהו החשבון הטכני שדרכו האפליקציה תתחבר לגיליון שלך בלי לבקש ממך להתחבר כל פעם.

1. גלוש אל [console.cloud.google.com](https://console.cloud.google.com/) והתחבר עם אותו חשבון גוגל שבו נמצא קובץ `wine_inventory`.
2. צור פרויקט חדש (או בחר קיים) — למעלה בפינה השמאלית "Select a project" → "New Project".
3. בתפריט החיפוש למעלה חפש **"Google Sheets API"** ולחץ **Enable**.
4. באותו אופן חפש **"Google Drive API"** ולחץ **Enable**.
5. בתפריט הצד: **IAM & Admin → Service Accounts → Create Service Account**.
   - תן לו שם כלשהו, למשל `wine-pos-app`.
   - אין צורך להעניק תפקידים (roles) מיוחדים — Continue → Done.
6. לחץ על חשבון השירות שיצרת → לשונית **Keys** → **Add Key → Create new key → JSON**.
   - יורד אליך קובץ JSON. **שמור אותו במקום בטוח** — זה "הסיסמה" של האפליקציה.
7. פתח את קובץ ה-JSON, ותמצא בו שדה `client_email` שנראה כך:
   `wine-pos-app@your-project-id.iam.gserviceaccount.com`

## שלב 2 — שיתוף הגיליון עם חשבון השירות

1. פתח את קובץ `wine_inventory` ב-Google Sheets.
2. לחץ **שיתוף (Share)** למעלה.
3. הדבק את כתובת ה-`client_email` מהשלב הקודם, ותן לו הרשאת **עורך (Editor)**.
4. שמור.

בלי השלב הזה האפליקציה לא תוכל לקרוא או לכתוב לגיליון.

## שלב 3 — העלאת הקוד ל-GitHub

1. פתח חשבון ב-[github.com](https://github.com) אם אין לך.
2. צור repository חדש (Public או Private — שניהם עובדים).
3. העלה אליו את כל הקבצים בתיקייה הזו: `app.py`, `requirements.txt`.
   - **אל תעלה** את `.streamlit/secrets.toml.example` עם ערכים אמיתיים — הוא רק תבנית.

## שלב 4 — פריסה ב-Streamlit Community Cloud (חינם)

1. גלוש אל [share.streamlit.io](https://share.streamlit.io) והתחבר עם GitHub.
2. **New app** → בחר את ה-repository שיצרת → קובץ ראשי: `app.py` → **Deploy**.
3. לפני שהאפליקציה תעבוד, צריך להזין את הסודות:
   - בתוך האפליקציה שנפרסה: **⋮ (שלוש נקודות) → Settings → Secrets**.
   - הדבק לשם תוכן בפורמט TOML לפי הדוגמה בקובץ `.streamlit/secrets.toml.example`,
     אבל עם **הערכים האמיתיים** מתוך קובץ ה-JSON שהורדת בשלב 1.
   - שים לב: את שדה `private_key` יש להדביק בדיוק כמו שהוא מופיע ב-JSON (כולל `\n`).
4. שמור, האפליקציה תיטען מחדש — ותקבל קישור קבוע כמו:
   `https://your-app-name.streamlit.app`

זהו הקישור שתשתמש בו מהיום מכל מכשיר — תשמור אותו בסימניות / תוסיף לדף הבית בנייד.

## מה האפליקציה עושה

- **קופה** — רישום מכירה מהירה, כולל תמיכה בפריטים עם "מחיר משתנה" שנקבע רק בזמן המכירה.
- **מלאי** — טבלת המלאי מהגיליון בזמן אמת, עם טופס להוספת יין חדש.
- **חייבים** — מעקב חוב פתוח ללקוח, וכפתור לרישום תשלום שמקטין את היתרה.
- **דוחות** — הכנסות היום/שבוע/חודש וסך החובות הפתוחים.

## מבנה הנתונים בגיליון

- **גיליון1** — טבלת המלאי הקיימת שלך. נוספה לה עמודה חדשה בסוף: `מחיר פתוח`.
- **sales_log** — יומן המכירות הקיים. נוספו לו שתי עמודות: `אופן תשלום`, `לקוח`.
- **customers** *(חדש)* — רשימת לקוחות ויתרות חוב.
- **payments_log** *(חדש)* — יומן תשלומים שהתקבלו על חשבון.

הטבלאות המקוריות שלך לא נמחקות ולא משתנות במבנה — רק נוספות עמודות/טאבים חדשים.

## הרצה מקומית (אופציונלי, למי שרוצה לבדוק לפני הפריסה)

```bash
pip install -r requirements.txt
mkdir -p .streamlit
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# ערוך את secrets.toml עם הערכים האמיתיים שלך
streamlit run app.py
```
